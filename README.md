# DawaSaathi website

The public website for DawaSaathi (दवा साथी), the medicine reminder app: a home page, the privacy policy and the terms of use, in English and Hindi.

Plain HTML and CSS with no build step, published by GitHub Pages from the `main` branch.

- `index.html`: home page
- `privacy.html`: privacy policy
- `terms.html`: terms of use
- `site.js`: the English/हिंदी switch (add `?lang=hi` to a link to open a page in Hindi)

The privacy policy and terms must say the same as the app (`lib/app/legal.dart` in the app repository). Change both together.
